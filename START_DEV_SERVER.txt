  http://localhost:8080/chart.html

🔧 故障排除
───────────────────────────────────────────────────────────────────────────

如果看不到數據：

1. 檢查是否生成了模擬數據
   node check-progress-simple.mjs

2. 檢查伺服器是否啟動
   http://localhost:8080 應該返回頁面

3. 檢查瀏覽器控制台
   按 F12 打開開發者工具
   查看 Console 標籤中的錯誤信息


💡 提示
───────────────────────────────────────────────────────────────────────────

• 修改代碼後無需重啟伺服器（靜態文件自動重載）
• 如果需要重啟，按 Ctrl+C 停止，再執行 npm run dev
• 清除瀏覽器緩存：Ctrl+Shift+Delete
