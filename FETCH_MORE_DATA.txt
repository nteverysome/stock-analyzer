📋 檢查當前進度
───────────────────────────────────────────────────────────────────────────

打開 PowerShell，執行：

  cd c:\Users\Administrator\Desktop\sotke4
  Get-Content backfill.log -Tail 30


你會看到類似：

  [1000/1962] ✅950 ⏭️50 ❌0 | 共 2,000,000 筆 | 1200s

這說明：
  • 已完成 1,000 支股票
  • 還剩 962 支
  • 已補抓 2,000,000 筆
  • 預計還需 2-3 小時


🚀 繼續補抓數據
───────────────────────────────────────────────────────────────────────────

執行以下命令繼續補抓：

  node scripts/fetch-5years-history.mjs > backfill.log 2>&1


說明：
  • 會自動跳過已有數據
  • 只補抓缺失部分
  • 繼續運行直到完成


📊 計算技術指標
───────────────────────────────────────────────────────────────────────────

補抓完成後，執行：

  node scripts/backfill-tw-indicators.mjs --history-full > indicators.log 2>&1


說明：
  • 計算 RSI、MACD、KD、MA
  • 自動跳過已有指標
  • 並行運行提高速度


⏳ 實時監控進度
───────────────────────────────────────────────────────────────────────────

在另一個 PowerShell 窗口執行（實時看進度）：

  Get-Content backfill.log -Tail 20 -Wait

  # 按 Ctrl+C 停止監控

補抓和計算都完成後：

  npx vercel dev

  # 2. 在瀏覽器打開
  http://localhost:3000/verify.html

  # 3. 點擊「開始驗證」確認數據完整


📝 並行執行（加快速度）
───────────────────────────────────────────────────────────────────────────

如果補抓已經完成一部分，可以同時進行計算指標：

  # 終端 1: 繼續補抓
  node scripts/fetch-5years-history.mjs > backfill.log 2>&1

  # 終端 2: 同時計算指標
  node scripts/backfill-tw-indicators.mjs --history-full > indicators.log 2>&1
